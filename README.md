# Resolve Assistant — локальный прототип

Окно Workflow Integration для DaVinci Resolve Studio: чат → версии композиции
Remotion / HyperFrames → предпросмотр → прозрачный MOV ProRes 4444 → Media Pool.

[Какие данные хранятся и передаются](PRIVACY.md) ·
[Аудит безопасности](docs/security-audit-2026-10-31.md)

До распространения EXE нужно закрыть открытые пункты аудита, включая доверие
сохранённому HTML предпросмотра и обновление нативных компонентов.

Это первая сборка для разработки на текущем Windows-компьютере, а не весь MVP
из технического задания. Она использует установленный Node.js 22+ и отдельный
Chrome Headless Shell для фонового рендера и браузерных тестов.
SDK берётся из вашей установки Resolve. Исходную папку проекта нельзя перемещать
после установки без повторного запуска установочного скрипта.

## Установка

Зависимости и FFmpeg уже подготовлены в этой рабочей папке. Для повторной
установки из терминала в папке проекта:

```powershell
npm.cmd install
node node_modules/ffmpeg-static/install.js
npm.cmd run browser:install
npm.cmd run install:resolve
```

Если запись в ProgramData запрещена, запустите установочную команду с правами,
разрешающими запись в каталог Workflow Integration Plugins. Не запускайте
сам Resolve или генерацию с повышенными правами.

Откройте **Resolve Studio → Workspace → Workflow Integrations → Resolve Assistant**.
Если Resolve работал во время установки, сохраните проект и перезапустите его.

## Первый запуск

1. Откройте проект Resolve. В блоке **«Папка проекта»** проверьте путь: если
   папка медиа не задана в Resolve, выберите её один раз. Затем нажмите
   **«Посмотреть тестовую композицию»**. Это локальный пример без AI.
2. Нажмите **«Рендер MOV»**, затем **«Добавить в Media Pool»**. Результат появится
   в `AI Assistant / Motion` текущего открытого проекта.
3. Нажмите **«Продолжить с ChatGPT»**, выполните вход в системном браузере и
   разрешите приложению использовать подписку. Авторизацию выполняет пользователь.
4. Выберите модель, доступный ей **уровень рассуждения** и движок, напишите
   сообщение в боковом чате и нажмите **«Отправить»**. Для новых композиций по умолчанию
   используется Remotion; он создаёт полноценную React-сцену.
5. Проверьте предпросмотр, выполните рендер и импорт отдельными кнопками.

Пример команды:

> Сделай надпись «Рост +35%» с оранжевым акцентом, плавным появлением снизу
> и прозрачным фоном. Крупная типографика, без лишних деталей.

### Чаты композиций и версии

Новая композиция получает V1 и собственный сохраняемый чат справа от предпросмотра.
Вопрос даёт текстовый ответ, просьба изменить сцену сохраняет новую внутреннюю
ревизию той же версии. Новая видимая V2/V3 создаётся только кнопкой **«+»** под
предпросмотром. Само нажатие не обращается к модели: напишите запрос в новом чате.

У каждой версии свои сообщения, черновик, настройки, ручная длительность и
включение видеоконтекста. В шапке показаны **«Чат Vn»** и основа. «+» фиксирует
выбранную основу: конкретный результат, полный исходник, историю и материалы
контекста. Последующие правки родителя её не заменяют. До первой правки дочерняя
версия показывает явно подписанный предпросмотр основы; собственный MOV ещё не создан.

Готовые jobs и MOV не перемещаются и не перезаписываются новыми правками.
Рендер и импорт действуют на выбранную ревизию логической версии. Кнопка результата
в сообщении открывает именно его ревизию. Переименование сохраняет пути файлов.

Схема v2 хранится в `jobs/.conversations/<id>.json`. При миграции старые видимые
версии сохраняются отдельно, неоднозначная общая переписка доступна как история
до обновления. Перед изменением старых метаданных создаётся уникальная резервная
копия `.pre-v2-*.bak`. Повторная загрузка не превращает ревизии в новые Vn.
Историческая композиция без projectId остаётся непривязанной при чтении; отправка
сообщения или «+» привязывает её к текущему проекту с отдельной `.pre-bind-*.bak`.

При ошибке или отмене сообщение остаётся в переписке; его можно вернуть в поле
кнопкой **«Повторить сообщение»**. Полная история хранится локально. В AI-запрос
входят до 80 последних успешных сообщений и 80 000 символов истории, полный
актуальный исходник и ограниченные сохранённые материалы. Пропуски обозначаются.

Разрешение и FPS наследуются из Resolve до ручного изменения. **«Из Resolve»**
возвращает наследование. Поля описывают следующее изменение; подпись предпросмотра
всегда описывает сохранённый результат. Для обновления достаточно переоткрыть
только окно Workflow Integration; главное окно Resolve закрывать не нужно.

### Контекст из In/Out

Отметьте **In и Out для видео** на активном таймлайне Resolve. Над полем
команды появится карточка с именем таймлайна, таймкодами и длительностью.
Она добавляет выбранный отрезок как контекст к вашему текстовому запросу.
Наведите мышь на карточку или перейдите к ней клавишей Tab и снимите галочку,
если новый захват видео не нужен. Карточка останется приглушённой: галочку можно вернуть.
Обновление In/Out сохраняет отключение; новая композиция включает контекст
снова. Без обеих видеометок новый захват не выполняется. История, исходник сцены
и ранее сохранённый контекст версии по-прежнему могут входить в запрос к OpenAI;
отключение карточки их не удаляет и не исключает из отправки.

Кадры извлекаются только после **«Отправить»**, до 12 изображений
по всему диапазону, включая начало и конец. Это изображение таймлайна,
а не необработанные исходники. Модель получает уменьшенные кадры с отметками
времени; полное видео и аудиофайл не отправляются. После получения кадров
позиция курсора восстанавливается, если пользователь не сменил таймлайн
или сам не переместил курсор. Изменившийся перед генерацией диапазон требует
обновления контекста, а не подменяется незаметно.

Речь получается средствами DaVinci: сначала читается готовая обычная/вложенная
расшифровка, затем при необходимости запускается поддерживаемая транскрибация
таймлайна как вложенного клипа или пересекающих диапазон исходных аудиоклипов.
Запуск происходит при явно отправленном сообщении, без внешнего STT и API-ключа.
Resolve может обрабатывать весь клип; в запрос отбираются только слова In/Out.
Для исходников учитываются подрезка, исходный таймкод, FPS и выключенный звук.
Неоднозначные retime/reverse/compound/multicam сообщаются как неподдержанные.

Интерфейс различает подготовку, полученную речь, успешное отсутствие речи и ошибку
SDK. **«Показать текст речи»** открывает отправленные фрагменты со временем от In.
Речь прежнего диапазона явно помечена как сохранённая. При недоступной речи
отправляются кадры и соответствующий статус; слова не придумываются. Ожидание
ограничено 120 секундами. Отмена прекращает дальнейшую подготовку/отправку;
уже запущенное распознавание внутри Resolve может продолжаться.

При валидных In/Out и включённой карточке **длительность берётся из диапазона**:
`(Out - In + 1) / FPS таймлайна`. Поле показывает одну десятую и заблокировано;
наведение или фокус обёртки объясняет изменение через In/Out. Отключение карточки
возвращает последнюю ручную длительность. В данных сохраняется точное время,
выходные кадры округляются по FPS результата. Контекстные клипы могут быть
короче 2 или длиннее 15 секунд. Предел установленного HyperFrames — 24 часа;
для больших сцен действуют ограничения ресурсов и времени рендера.

Материалы сообщения сохраняются независимо от ответа модели в
`jobs/.contexts/<snapshot-id>/`, включая текстовый ответ без создания job.
Потомки и следующие сообщения версии получают зафиксированные материалы основы;
это не включает автоматически новый выключенный текущий видеоконтекст.
В запрос передаются до 12 изображений, для каждого указан снимок и время;
сохранённая речь ограничена 24 000 символами. Пропуски отмечаются.
Старые `jobs/<id>/context/` безопасно копируются в новую схему, оригиналы остаются.
Временные capture-файлы удаляются по завершении операции.

Фактическая совместимость транскрибации через JavaScript SDK на материале с речью
требует отдельной живой проверки; автоматические тесты не заменяют её.

В списке **«Разрешение»** используются единые названия и базовые размеры.
Флажок **«Вертикальный»** меняет местами ширину и высоту; рядом показаны
пропорции, например 16:9 или 9:16. Точные нестандартные размеры из Resolve
сохраняются, а для квадратного кадра ориентация не требуется.

Во время генерации статус показывает, продумывает ли модель сцену или уже
пишет композицию. Активная работа больше не прерывается фиксированным
четырёхминутным таймером. Сохраняются ограничения: остановка при трёх минутах
без новых данных и общий предел 15 минут. Запрос можно отменить кнопкой;
частичный ответ не превращается в готовую композицию.

## Подписка ChatGPT

Реализован официальный Sign in with ChatGPT: отдельная регистрация приложения,
PKCE/state/nonce, проверка подписи ID token, DPAPI-хранилище текущего пользователя,
обновление токена и выход. Codex app-server использует OAuth ChatGPT-plan provider
с отдельным профилем. API-ключи и конфигурация других Codex-приложений не читаются.

Сам факт входа не доказывает доступность модели: проверкой будет первый успешно
завершённый запрос. Доступ зависит от аккаунта, тарифа, политики и региона.
Использование может затрагивать разрешённые пользователем ChatGPT credits;
покупки и переключения на API-биллинг приложение не выполняет.

Источники: [SIWC](https://developers.openai.com/siwc/token-sharing-open-source),
[app-server](https://developers.openai.com/siwc/token-sharing-open-source/codex-app-server).

## Что умеет эта сборка

- Remotion 4.0.534: полноценный TSX с React-компонентами, SVG, графиками,
  последовательностями, интерполяцией и пружинной анимацией. Исходник сохраняется
  рядом с результатом в `source.tsx`.
- HyperFrames 0.8.221: совместимый прежний движок для текстов, прямоугольников,
  эллипсов, появления и исчезновения. Старые композиции продолжают использовать
  свой движок.
- Вручную 2–15 секунд; с видеоконтекстом — длительность In/Out. Размеры от 360 до 4096 пикселей по каждой стороне. Готовые
  форматы включают FHD, 3K, UHD и DCI 4K, вертикальные и квадратные варианты.
- Выбор 24, 25, 30, 60 и 120 fps; точная дробная частота наследуется из Resolve.
  Длительность согласуется с целым числом кадров.
- Уровни рассуждения берутся из каталога выбранной модели; неподдерживаемые
  значения недоступны. Настройки модели, уровня и выбранного движка запоминаются.
- React-код компилируется как данные и выполняется только в изолированном
  браузере. Он не исполняется в Node или процессе с доступом к Resolve.
  Разрешены установленные React/Remotion и встроенный SVG; загрузка произвольных
  npm-пакетов, сеть и доступ к файлам пользователя не предоставляются.
- Предпросмотр изолирован в iframe без доступа к Resolve, сети и credentials.
- Композиции сохраняются в `<папка проекта>/jobs/<id>/`, финальный файл —
  `motion.mov`. Используется папка медиа из настроек Resolve или выбранная
  вручную папка, запоминаемая для ID проекта в `.data/workspaces.json`.
- Проекты в библиотеке Resolve могут не иметь отдельной файловой папки.
  Каталог базы данных не используется для результатов. Старые файлы остаются
  на месте, включая прежний `workspace/jobs`; ссылки Media Pool сохраняются.
- Повторный импорт проверяет сохранённый media ID, смена проекта блокирует импорт.

Пока не входят: фоновые задачи установщика, вложения, удаление фона,
вставка на таймлайн, произвольный генерируемый JavaScript и публичный EXE.
`davinci-resolve-mcp` для этой связки не требуется: используется прямой SDK.

## Проверки

```powershell
npm.cmd test
npm.cmd run check
npm.cmd run smoke
node scripts/smoke-upgrade.cjs remotion 640 360 29.97 2
```

`smoke` выполняет реальный рендер и проверяет декодированный альфа-канал.
`smoke-upgrade.cjs` проверяет выбранный движок, размеры и частоту; результаты
сохраняются в `workspace/verification/`. Проверка не обращается к AI.
Отчёт: `workspace/smoke/verification.json`.

Рендер обоих движков и браузерные тесты используют Chrome Headless Shell из
`.data/browser`, версия привязана к закреплённой версии Puppeteer. Системный
Edge/Chrome не используется: даже в headless-режиме полноценный браузер создаёт
нативные окна и может интегрировать вкладки с Alt+Tab. Если браузер отсутствует,
выполните `npm.cmd run browser:install`; установка плагина также выполняет этот
шаг. После обновления Puppeteer повторите установку браузера. Автоматического
перехода на Edge нет. Обычное окно плагина по-прежнему работает внутри Resolve.

На текущем компьютере 30 октября 2026 проверена полная цепочка с личным аккаунтом:
Sign in with ChatGPT → генерация → предпросмотр → прозрачный MOV → Media Pool.
Подтверждён один тестовый сценарий на Resolve Studio 21.1.0.14. Подробности и
ограничения проверки — [docs/compatibility-local.md](docs/compatibility-local.md).
Автотесты не заменяют повторную проверку других конфигураций и сценариев.

## Зависимости

Версии закреплены в package-lock.json. Перед публичным распространением
проверьте лицензии HyperFrames/GSAP/FFmpeg/Codex и условия использования SDK.
Текущая сборка устанавливает SDK-бинарник из уже установленного Resolve только
на этот компьютер. Телеметрия HyperFrames отключена через документированные
параметры окружения. Установщик не меняет PATH, настройки Resolve и другие MCP.
