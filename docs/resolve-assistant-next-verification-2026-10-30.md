# Проверка доработок Resolve Assistant

Дата: 30 октября 2026 года. Основа: `TZ_resolve_assistant_next.md`.

## Реализовано

- Новая композиция с V1, новые видимые версии только через «+», отдельные сообщения/черновики/параметры версии. Правка создаёт внутренний неизменяемый job; MOV предыдущей ревизии сохраняется. Кнопки результатов выбирают конкретную ревизию, рендер/импорт проверяют её принадлежность и выбор.
- Зафиксированная основа дочерней версии: исходник, история, параметры, манифест ресурсов и постоянные снимки кадров/речи. Снимки сохраняются до AI, в том числе для текстовых ответов. Вложения снабжены ID исходного снимка, ограничения размера запроса явно отмечаются.
- Schema v2, уникальные резервные копии старых метаданных, сохранение старых видимых результатов и полной общей истории. Старые jobs/MOV не перемещаются. Кадры и речь из старого `jobs/<id>/context/` копируются в постоянные снимки с проверкой путей. Повторная загрузка не дублирует версии или ответы. Ошибка одного документа не отключает остальные.
- Старые композиции без projectId не привязываются фоновым чтением. Явная отправка или «+» привязывает композицию к текущему проекту с отдельной резервной копией; старые результаты получают ту же эффективную область доступа.
- Длительность по доверенному текущему In/Out при включённом контексте, отображение до десятых и доступная с клавиатуры подсказка. Ручное значение хранится отдельно и восстанавливается, включая 15 секунд при 29.97 FPS. Оба движка поддерживают контекст короче 2 и длиннее 15 секунд, кадры округляются по выходному FPS.
- Чтение существующей обычной/вложенной речи Resolve, запуск нативной транскрибации только при подготовке явно отправленного сообщения, консервативный пересчёт источников. Отдельные статусы речи, просмотр текста, таймаут, отмена и проверка проекта/диапазона. Внешний STT не добавлен.

## Что проверено на живом приложении

- Read-only Python SDK вне sandbox подключился к установленному Resolve. В первом состоянии текущего таймлайна не было; позднее пользователь открыл материал в тестовом проекте.
- В настоящем окне Workflow Integration визуально наблюдались новый чат V1, кнопка «+», история до обновления и текущий In/Out `Timeline 1` длительностью около 2.402 с. Поле длительности показывало 2.4 с и было заблокировано; подпись старого предпросмотра продолжала показывать длительность сохранённого результата.
- Главное окно Resolve и монтаж не закрывались и не менялись автоматизацией.

## Незавершённая живая приёмка

Пользователь остановил управление окном физической клавишей **Esc** до отправки проверочного сообщения. После этого UI-вызовы прекращены.

**Нативное распознавание через JavaScript Workflow Integration на реальном материале с речью не проверено.** Методы подтверждены установленным SDK и покрыты автоматическими сценариями, но это не подтверждает успешное выполнение через живой JS SDK. Новый цикл `V1 → + → V2 → вопрос → правка` проверен автоматически; живой цикл с настоящей моделью, повторное открытие после последних исправлений и сохранение отдельного скриншота живого Resolve остаются невыполненными.

Для завершения живой приёмки потребуется возобновить управление окном, переоткрыть только интеграцию и явно отправить сообщение на тестовом диапазоне с речью. Сверить просмотр текста и фактический статус; при неподдерживаемом API зафиксировать ошибку, не заявляя, что распознавание работает.
