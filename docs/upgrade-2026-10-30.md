# Обновление Resolve Assistant — 30 октября 2026

## Что добавлено

- Полноценные React/Remotion-композиции: модель создаёт TSX-компонент,
  а не только список стандартных фигур. Поддерживаются собственные компоненты,
  SVG, графики, последовательности, интерполяция и пружинная анимация.
- Переключатель Remotion / HyperFrames. Старые композиции используют прежний
  движок; для новых по умолчанию выбран Remotion.
- 3K, UHD и DCI 4K, вертикальные и квадратные форматы; точные параметры
  активного таймлайна Resolve с запасным чтением настроек проекта.
- Выбор 24 / 25 / 30 / 60 / 120 кадров в секунду и наследование дробной частоты.
  Ручной выбор сохраняется при обновлении сведений о проекте.
- Переименование с сохранением истории, путей готового MOV и Media Pool ID.
- Выбор доступного модели уровня рассуждения; сохранение предпочтений.
- Более компактная нейтральная тёмная панель и исправленное выделение поля
  команды. Предпросмотр показывает параметры сохранённой композиции, пока
  пользователь меняет настройки следующей версии.

## Границы проверки

Новая AI-генерация через личную подписку и повторный импорт в Media Pool
в этом обновлении не выполнялись. Во время живой проверки открытого окна
Resolve или Resolve Assistant не было; чтение настроек SDK проверено
автотестами, а не текущим открытым проектом.

Remotion использует настоящий Player с покадровым захватом в изолированном
браузере и кодированием FFmpeg. Поддерживаются установленные React/Remotion
и встроенный SVG; внешние медиа, произвольные пакеты и асинхронные ресурсы
в эту сборку не входят. Размер ограничен 4096 пикселями по каждой стороне,
длительность — 2–15 секунд с согласованием целого числа кадров.

Для загрузки обновлённой панели откройте Resolve и заново откройте
Workspace → Workflow Integrations → Resolve Assistant.
