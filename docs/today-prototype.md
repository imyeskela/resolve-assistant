# Локальный прототип, 30 октября 2026

Основа — предоставленное ТЗ v0.2. Текущая установленная версия Resolve:
21.1.0.14. Проверять Studio и Workflow Integration на реальном запуске.

## Сценарий
Окно из Workspace → Workflow Integrations → команда → композиция →
предпросмотр → MOV ProRes 4444 → отдельный импорт в Media Pool.

Первый движок HyperFrames 0.8.221. Remotion и MCP не обязательны для этого
сценария. davinci-resolve-mcp — независимый сервер управления через Scripting
API; собственное окно подключается к установленному Workflow Integration SDK.

## Границы сегодняшней сборки
- Windows x64, локальная установка для разработки из этой папки.
- Node 24 уже установлен на компьютере; runtime выбирается установочным скриптом.
- Sign in with ChatGPT и закреплённый Codex app-server, без API key fallback.
- Прозрачный фон, 30 fps, 16:9 / 9:16 / 1:1, длительность 2–15 секунд.
- Модель возвращает валидируемое JSON-описание доверенной композиции: текст,
  фигуры, положение, цвет и варианты появления. Произвольный код не исполняется.
- Отдельные процессы для AI и рендера. Доступа AI к Resolve и исходным медиа нет.
- Выводы сохраняются постоянно в workspace; новые версии не заменяют старые.
- Импорт только явной кнопкой с проверкой текущего проекта; таймлайн — позже.
- Без удаления фона, вложений, второго движка, публичного EXE и обновлений.

## Проверка
Валидатор, защита от HTML/script/CSS-инъекций, OAuth state/PKCE и протокол
проверяются автоматически. Локальный рендер проверяется реальным MOV с альфой,
размером и длительностью. Вход в личный аккаунт и подтверждение разрешения
пользователь выполняет в системном браузере. Загрузка SDK и импорт проверяются
в настоящем Resolve. Эти проверки не подменяются моками.

## Порядок работы
1. Проверяемые контракты композиции и OAuth, затем минимальная реализация.
2. Закреплённые зависимости и реальный тест HyperFrames на Windows.
3. Ограниченный controller, защищённые credentials, app-server без shell tools.
4. Окно Workflow Integration и импорт результата через установленный SDK.
5. Проверки, установка на эту машину, отчёт о реально подтверждённых функциях.
